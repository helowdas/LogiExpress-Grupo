# Solución en Paradigma Lógico (Prolog)

Carpeta destinada a la implementación del motor analítico usando el **Paradigma Lógico**.

Contendrá el predicado principal de menú (`iniciar` / `menu`) y las reglas de búsqueda
sobre el grafo de vuelos, según el plan de ejecución del proyecto (ver `../docs/plan-ejecucion.md`).

Ejecución prevista (desde la raíz del repositorio):

```bash
swipl -s prolog/main.pl
```

```prolog
?- iniciar.
```
