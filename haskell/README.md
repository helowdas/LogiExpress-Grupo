# Solución en Paradigma Funcional (Haskell)

Carpeta destinada a la implementación del motor analítico usando el **Paradigma Funcional**.

Contendrá el módulo `Main` con el menú interactivo de consola (CLI) y la lógica del grafo
de vuelos, según el plan de ejecución del proyecto (ver `../docs/plan-ejecucion.md`).

Ejecución prevista (desde la raíz del repositorio):

```bash
runghc haskell/Main.hs
```
